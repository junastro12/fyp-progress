Perkara data yang perlu disahkan

  • Tiada lajur EPF Balance. Fail hanya ada AUM. Hassan & Othman (2018) takrif EPF Balance sebagai caruman tolak pengeluaran, jadi data baharu perlu diambil dari Laporan Tahunan EPF. Jangan hanya tukar nama lajur.
  • Unit AUM salah label. Header tulis RM'000, tetapi nilai 2014 = 636,542 sepadan RM636.5 bilion. Maknanya RM juta (seperti Table 3.1).
  • Unit GDP salah label. Header tulis USD Bilion, tetapi nilai 2014 = 1,106,443 sepadan RM1,106.6 bilion dalam Hassan & Othman. Maknanya RM juta. Table 3.1 perlu dibetulkan.
  • POP65 tahun 2002 = 931.5 turun daripada 1,035.4 (2001) dan naik ke 1,118.9 (2003). Nampak seperti kesilapan taip, semak sumber DOSM.
  • AUM 1997 = 107,420 turun daripada 1996 lalu melonjak 36% pada 1998. Semak sumber.
  • 2025 tiada data AUM. Skop Bab 1 kata 1991–2025, model guna 1991–2024 (N=34). Seragamkan.
